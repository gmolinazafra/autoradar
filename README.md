# AutoRadar · MVP 0.1

Panel web para buscar autocaravanas con cama isla en España. Búsquedas externas en Wallapop y Milanuncios, guardado manual de anuncios sin duplicados.

## Uso

```bash
npm install
npm run dev
npm run build
```

Desplegar en Vercel como proyecto Vite, salida `dist`.

## Estado

La interfaz, búsquedas externas y guardado local funcionan. Todavía no existe rastreo automático ni envío de avisos a Telegram. Los datos se guardan en el navegador, no introduzcas tokens secretos.
